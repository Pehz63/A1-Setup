# Verify menu paths

Do not give Unity or Meta XR menu paths or window names from memory. Check them in the installed package source (Library/PackageCache) first, or say they are unverified and give a way to find them.

Reason: a wrong Building Blocks path was given during A4 and the user could not find the window. Unity 6000.6.3f1 and Meta XR SDK 207.0.0 differ from older tutorials.
