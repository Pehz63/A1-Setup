Part 2: Send Camera Frames to the LLM
Now you will modify `A3TalkingCube.cs` so that when the user speaks, the cube also captures a snapshot of what the user sees and sends it alongside the text to the LLM.

1. Add a Reference to A4CameraFrameProvider

In A3TalkingCube.cs, add a serialized field:

[Header("Camera")]
[SerializeField] private A4CameraFrameProvider cameraFrameProvider; 
Wire it up in the Inspector by dragging the GameObject that has A4CameraFrameProvider (your InteractionManager)

2. Capture a Frame in the Pipeline

In the `RunPipelineAsync` method, after the STT step produces userText and before adding the user message to history, capture a frame:

Texture2D snapshot = null;
if (cameraFrameProvider != null)
{
    snapshot = await cameraFrameProvider.CaptureFrameAsync();
}
3. Attach the image in the message

Replace the line that adds the user message to history:

history.Add(new JObject { ["role"] = "user", ["content"] = userText }); 
with logic that sends both text and image when a snapshot is available:

// Always store text-only in history to avoid sending images repeatedly
history.Add(new JObject { ["role"] = "user", ["content"] = userText });

// Build the request messages: use history as-is for all past turns,
// but replace the last message with a multimodal version if we have a snapshot
var requestMessages = (JArray)history.DeepClone();

if (snapshot != null)
{
    string snapshotBase64 = Convert.ToBase64String(snapshot.EncodeToJPG(75));
    requestMessages[requestMessages.Count - 1] = new JObject { 
        ["role"] = "user", 
        ["content"] = new JArray { 
            new JObject { 
                ["type"] = "image_url", 
                ["image_url"] = new JObject { 
                    ["url"] = "data:image/jpeg;base64," + snapshotBase64 
                } 
            }, 
            new JObject { ["type"] = "text", ["text"] = userText } 
        } 
    };
}
Then build the chat request body with requestMessages instead of history:

var chatRequest = new JObject { ["model"] = chatModel, ["messages"] = requestMessages };
This way:

history always stores plain text — keeps token costs low across turns
requestMessages is a throwaway copy where only the latest user message includes the image
The LLM still sees the full conversation context, but only one image per request
4. Update the System Prompt and Test it

Update the prompt to something like "You are a friendly talking cube with eyes. You can see what the user sees through their headset camera. When the user asks about something in their view, describe what you see. Keep answers short."

Hold the trigger and say "What do you see?" — the cube should describe objects in your view.
Point at a specific object and ask "What color is this?" — verify the cube's answer matches reality.
